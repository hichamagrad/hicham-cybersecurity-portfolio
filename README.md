# Hicham AGRAD — Portfolio

Personal portfolio site, built with Next.js (App Router) and Tailwind CSS.

- **Languages**: English, French, Arabic (with full RTL support), via `next-intl`
- **Theme**: light / dark mode toggle
- **Sections**: About, Skills, Projects, Experience, Certifications, Contact

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Tech stack

Next.js 16, React 19, TypeScript, Tailwind CSS v4, next-intl.
